Wrap up this session by:
1. Extracting cross-session learnings to Memory
2. Saving summary to Notion
3. Exiting cleanly

## Workflow

1. Execute /memorize - extract and store learnings (interactive)
2. Execute /notion with arguments: `$ARGUMENTS`
3. Confirm both saves completed
4. Display: "✅ Wrap-up terminé. Tape /exit ou Ctrl+D pour quitter."

## Usage

- `/wrap` - Memorize + Notion (Quick priority, inferred title) + exit
- `/wrap D2` - Memorize + Notion with D2 priority + exit
- `/wrap W5 "Feature implementation"` - Full specification
