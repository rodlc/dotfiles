# Memory Storage Patterns

## Types and Retention

| Type | Tag | Retention | Examples |
|------|-----|-----------|----------|
| **semantic** | reference | 180d | ☑️ Convention, API pattern, market data |
| **episodic** | standard | 90d | ☑️ Decision with context, trade-off, bug fix |
| **procedural** | critical | 365d | ☑️ Workflow, hook, shell command |

## Format

```python
store_memory(content="[TYPE] Subject", metadata={"tags": "reference", "type": "semantic"})
```

## Examples

### Semantic (reference)
```python
store_memory(
    content="Rails convention: Controllers in app/controllers inherit from ApplicationController",
    metadata={"tags": "reference,rails,convention", "type": "semantic"}
)
```

### Episodic (standard)
```python
store_memory(
    content="Decision: Used PostgreSQL JSONB for flexible schema instead of separate tables. Trade-off: flexibility vs query performance",
    metadata={"tags": "standard,decision,postgresql", "type": "episodic"}
)
```

### Procedural (critical)
```python
store_memory(
    content="Workflow: Before Rails PR → git pull main → rails db:migrate → check for assets/migrations changes",
    metadata={"tags": "critical,workflow,rails", "type": "procedural"}
)
```

## DO NOT Store

❌ Content already in git
❌ Session temporary data
❌ Verbatim conversations

## Anti-patterns (Noise Sources)

### Empty session consolidations
Auto-generated by `session-end.js` hook — generic topic lists with no signal.
Signature: `# Session Summary - {project}` + only `## 🎯 Topics Discussed` with keyword lists.
Fix: `enableSessionConsolidation: false` in `~/.claude/hooks/config.json`

### Skill/framework instruction text
Hook captures skill scaffolding from conversation transcript.
Signature: contains "ExitPlanMode", "Proceed with workflow", "Call ExitPlanMode tool".
Fix: disabled by turning off session consolidation.

### Duplicate cluster summaries
Auto-generated "Cluster of N related memories about X" entries.
Zero signal — just metadata about other memories.
Delete via: `retrieve_memory("Cluster of related memories about")`

## Advanced Functions

### Quality System

MCP Memory includes quality scoring (requires activation in ~/.zshrc):

```bash
export MCP_QUALITY_SYSTEM_ENABLED=true
export MCP_QUALITY_BOOST_ENABLED=true
export MCP_QUALITY_BOOST_WEIGHT=0.3  # 70% semantic + 30% quality
```

**Quality scoring workflow:**
1. `retrieve_memory` returns quality scores automatically
2. Use `rate_memory(hash, rating)` to manually rate (1-5)
3. `get_memory_quality(hash)` shows quality score
4. `analyze_quality_distribution` provides overview
5. `retrieve_with_quality_boost` prioritizes high-quality memories

**Example:**
```python
# Retrieve memories with quality scores
memories = retrieve_memory("api authentication", n_results=10)

# Rate a memory
rate_memory(hash="abc123...", rating=5)

# Check quality distribution
analyze_quality_distribution()
```

## Tag Taxonomy

### Tier 1: Retention (Required)
- `critical` (365d): Identity, credentials, permanent refs
- `reference` (180d): Conventions, preferences, architecture
- `standard` (90d): Tooling, active projects, decisions
- `temporary` (30d): Session context, ephemeral

### Tier 2: Type (Semantic)
- `identity`: Personal data (name, NIR, contacts)
- `convention`: Patterns, styles, rules
- `workflow`: Procedures, scripts, automation
- `tooling`: MCP, CLI, configs
- `decision`: Trade-offs, choices with context

### Tier 3: Domain (Optional)
- `mcp`, `dotfiles`, `gmail`, `notion`, `rails`, `claude-code`, etc.

## Best Practices

### Quality-Based Retention
- High quality (≥0.7) → critical (365d)
- Medium (0.5-0.7) → standard/reference (90-180d)
- Low (<0.5) → temporary (30d) or delete

### Pattern-Based Storage
Store memories with importance indicators:
- "important", "critical", "remember"
- "resolved", "fixed", "configured"
- "decision:", "convention:", "workflow:"
- "[PROCEDURAL]", "[REFERENCE]", "[CONVENTION]"

### Avoid Association Pollution
DO NOT manually create "association discovered" memories - these are auto-generated by consolidation and should be cleaned periodically.
